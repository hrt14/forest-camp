# FOREST CAMP

雪原でマキ・肉・石を集め、炉や設備を強化し、作業員によって資源回収を自動化していく拠点育成ゲームのMVPです。

## 方向性

- ホワサバ広告で見かける「資源を拾って設備に投入し、少しずつ自動化する」体験
- 経営・放置・シェルター運営系ゲームの気持ちよさ
- 名前・素材・UIはコピーせず、独自の雪原キャンプゲームとして実装

## 実装済み

- マキ・肉・石の手動回収
- 中央の炉付近で自動納品
- 炉の温度ゲージと寒さペナルティ
- 炉・倉庫・宿舎・伐採所・狩場・石切場・防壁
- 設備の建設/強化
- 作業員配置による自動回収
- 設備レベルによる新要素解放
- クエストガイド
- localStorage保存
- オフライン放置報酬
- スマホ操作用バーチャルパッド
- PC操作（WASD / 矢印キー）

## ローカル起動

```bash
npm install
npm run dev
```
